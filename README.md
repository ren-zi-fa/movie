# 🎬 Bajakin

🚨 **Disclaimer: Proyek ini hanya dibuat untuk pembelajaran dan eksperimen teknis. Segala bentuk distribusi konten bajakan adalah ilegal dan tidak didukung.**

**Bajakin** adalah platform streaming film bajakan (hanya untuk eksplorasi teknis), dibangun menggunakan stack modern berbasis **Next.js 15**, **React 19**, dan **Tailwind CSS**.

🌐 Live Demo: [https://bajakin.netlify.app/](https://bajakin.netlify.app/)

---

## 🛠️ Tech Stack

| Kategori         | Tools                                                                                                                                 |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| Framework        | [Next.js 15](https://nextjs.org/) + [React 19](https://react.dev/)                                                                    |
| UI               | [Tailwind CSS](https://tailwindcss.com/), [Lucide Icons](https://lucide.dev/), [Radix UI](https://www.radix-ui.com/)                  |
| Data Fetching    | [SWR](https://swr.vercel.app/), [Axios](https://axios-http.com/)                                                                      |
| State Management | [Zustand](https://zustand-demo.pmnd.rs/), [RxJS](https://rxjs.dev/)                                                                   |
| Web Scraping     | [Hono](https://hono.dev/) + [Cheerio](https://cheerio.js.org/)                                                                        |
| Carousel         | [Embla Carousel](https://www.embla-carousel.com/)                                                                                     |
| Virtual List     | [react-window](https://react-window.now.sh/), [react-virtualized-auto-sizer](https://github.com/bvaughn/react-virtualized-auto-sizer) |
| Dark Mode        | [next-themes](https://github.com/pacocoursey/next-themes)                                                                             |

---

## ✨ Fitur Utama

- 🔍 Pencarian real-time film dengan RxJS
- 🎞️ Detail film lengkap: rating, genre, negara, trailer, deskripsi, aktor
- 🧠 Bookmark film favorit menggunakan Zustand + localStorage
- 📺 Pemutar film (iframe embed)
- 🌓 Dukungan dark mode
- ⚡ Fast-loading UI dengan `react-window` untuk performa tinggi
- 📱 Responsif dan mobile-first
